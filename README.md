# HR Analytics Dashboard | Power BI

## Project Overview
This project presents an interactive HR Analytics Dashboard created using Microsoft Power BI.

## Key Insights
- Total and Active Employees
- Employee Attrition Rate
- Attrition by Job Role and Gender
- Employees by Department
- Education Field Analysis
- Monthly Income vs. Attrition
- Interactive Filters

## Tools Used
- Microsoft Power BI
- Data Visualization
- HR Analytics

## Project Objective
To analyze employee data and understand workforce trends and attrition patterns.
